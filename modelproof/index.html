      Words used here
      
      
        
      Agent graph
      Agents and the routes they use to hand work to one another.
      
        
      Model and scenario
      A model is the AI that runs the agents. A scenario is one task used to test their behavior.
      
        
      Generation
      A version of the graph's instructions with its own recorded test results.
      
        
      Held, Broke, Stopped
      The behavior held, a check found a violation, or the run ended before the checks finished.
      
        
      Harden
      Add two instructions to the graph and view the recorded results for that version.
      
        
      Declaration
      A list of the models that held in every scenario for this generation.
      
        
      Compatibility lookup
      Yes means the model qualified. No means it was tested and did not qualify. Not tested means the declaration has no record for that graph and model.
