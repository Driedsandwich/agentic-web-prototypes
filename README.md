# Agentic web prototypes

Clickable prototypes for five open agentic web tools, built for early user testing. Each folder is a static page that runs on sample data only: nothing is sent, no AI model runs, and nothing costs money.

- `edition-switch/`
- `benefit-commons/`
- `modelproof/`
- `pliant/`
- `docmesh/`

Each folder has its own README and `node --test` tests. Names are provisional. Licensed under the Apache License 2.0 (see `LICENSE`).
