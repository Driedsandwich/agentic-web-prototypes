      Words used here
      Documentation network
      A set of tools that other sites can call to read sections of a document.
      MCP
      A protocol for calling tools, such as a tool that reads a section.
      Endpoint / callable URL
      The web address a caller uses to reach a network or server.
      Origin
      The identity of the caller's site that the browser uses for cross-site checks.
      CORS
      Browser rules for requests between different origins. The server uses response headers to say which origins it allows.
      Access-Control-Allow-Origin
      A response header that says which caller origin the server allows.
      Preflight
      A check the browser may send before making a cross-origin request.
      Peer Preflight / Pass
      Peer Preflight checks whether one site can call another. Pass is the sample outcome shown here.
      Manifest
      A small JSON file that names the network and identifies which tool reads a section.
