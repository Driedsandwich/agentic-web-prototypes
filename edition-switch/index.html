Words used here
Edition
The flyer prepared for a particular place, such as a venue handout or the event page.
Rights holder
The source that sets how a photo or map may be used.
Usable
The sample rules allow the selected uses when you follow the listed terms.
Needs review
The sample rules call for a check before publication.
Not for this use
At least one selected destination is outside the current terms.
Counteroffer
A different photo, crop, or set of terms offered in response to a request.
Counter
Ask the rights holder to change the proposed terms.
Terms version
The revision of the sample usage terms, such as v3.
Peer Preflight / Pass
A local check before a sample request. Pass means the required request fields are present.
Usage check
Applying a photo’s sample terms to the selected publishing destinations.
